Mr.Python: nauka Pythona małymi krokami

Ścieżka z 6 części, 14 lekcji i 72 zadań w czterech typach. Serca, punkty XP, seria dni i cel dzienny utrzymują rytm nauki.

Na co patrzeć: czysta warstwa domain bez zależności od Androida, StateFlow w ViewModelu i testy uruchamiane w GitHub Actions.

  • Kotlin 2 506 linii
  • Jetpack Compose, Material 3
  • ViewModel + StateFlow
  • 20 testów jednostkowych
  • GitHub Actions

Jak jest zbudowana

Kod jest podzielony na trzy warstwy. W domain jest czysta logika: sprawdzanie odpowiedzi, serca, punkty, seria dni, przebieg lekcji. W data jest treść kursu i zapis postępu. W ui są ekrany Compose.

Logika nie zależy od Androida, więc testy działają bez emulatora. Osobny test sprawdza treść kursu: czy identyfikatory zadań są unikalne i czy każda poprawna odpowiedź przechodzi przez własny mechanizm sprawdzania.

Zasady z kodu

Pięć serc. Błąd kosztuje jedno, a serce odnawia się co 20 minut. Źle rozwiązane zadanie wraca na koniec lekcji. Lekcja daje 10 XP i 5 więcej za przejście bez błędu.

Wynik programu jest porównywany linia po linii. Spacje na brzegach nie mają znaczenia, wielkość liter ma, bo Python wypisuje True, a nie true.

Demo na żywo

Cztery zadania z pliku CourseContent.kt. Sprawdzanie odpowiedzi i serca działają według AnswerChecker i Rules z aplikacji.
