# Portfolio programistyczne — Łukasz

Uniwersalne portfolio do publikacji na GitHub Pages. Nie zawiera nazw firm, do których wysyłane były wcześniejsze aplikacje.

## Strony

- `index.html` — strona główna i wybór obszaru.
- `mobile/index.html` — Mobile Engineering: Flutter, Android, Kotlin.
- `systems/index.html` — Systems Engineering: Python, UDP, SQLite, diagnostyka.
- `agentic/index.html` — Agentic Development: AI coding agents, code review, testy.

## Publikacja

1. Repozytorium: `https://github.com/LukaszTM/Portfolio`.
2. Prześlij **zawartość tego folderu** do katalogu głównego gałęzi `main` (a nie folder `site`).
3. Ustaw Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)`.
4. Adres: `https://lukasztm.github.io/Portfolio/`.


> Na stronie przedstawiane są autentyczne projekty oraz oznaczone wizualizacje poglądowe. BoxBox Academy ma prywatny kod źródłowy; publicznie dostępny jest instalator beta.
